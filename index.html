Murphy Family Assistant

This is a private, personal household automation project. It is not a public product and is not available for anyone outside this family to use or sign up for.

The assistant (built on the open-source Hermes Agent) runs on behalf of one family, over a private Telegram group, to help with household tasks such as:

  • Reading and answering questions about shared family Google Calendars (schedule, upcoming events, conflicts)
  • Creating calendar events when a family member asks it to
  • Reading and writing simple household notes (recipes, shopping lists, reminders) in a private family knowledge base

Privacy Policy

This application accesses Google Calendar data (and no other Google service) solely to provide the household automation described above, for the sole benefit of the family members who use it.

  • What is accessed: Calendar event data (titles, times, locations, attendees) for a small number of calendars explicitly configured by the household.
  • How it is used: Solely to answer questions about the family's schedule, surface upcoming events, and create new events when a family member requests it.
  • Who can access it: Only the family members who operate this private instance. Calendar data is never sold, shared with advertisers, or made available to any third party.
  • Infrastructure: The application runs on infrastructure controlled by the family (Railway) and uses Anthropic's Claude API to process requests. No calendar data is used to train any AI model.
  • Data retention: Calendar data is not stored outside of what Google's API itself returns per request; the application does not maintain a separate calendar database.
  • Revoking access: Access can be revoked at any time via Google Account permissions.
